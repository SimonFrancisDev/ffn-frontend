# Fin Freedom Network Video Production Package

## Contents

- `BRAND_AND_ORBIT_GUIDE.md`: brand identity, official language, level map, complete orbit rules, payment roles, eligibility, escrow, recycle, and ID1 fallback.
- `ORBIT_DIAGRAMS.svg`: editable vector diagrams for P4, P12, and P39.
- `ORBIT_DIAGRAMS.preview.png`: ready-to-share raster preview of the diagrams.
- `ORBIT_RADIAL_DIAGRAM.svg`: editable circular orbit presentation.
- `ORBIT_RADIAL_DIAGRAM.png`: ready-to-share circular orbit presentation.
- `VIDEO_STORYBOARD.md`: scene order, narration direction, visuals, examples, and required disclaimer.

## Included official assets

- `assets/official_logo_dark.png`: logo for dark backgrounds.
- `assets/official_logo_light.png`: logo for light backgrounds.
- `assets/title_bar_logo.png`: compact logo.

## Production instruction

Use the SVG as the structural source. Do not redraw position relationships from memory. Use the guide for payment narration, because P12 and P39 recipients depend on the participant's position and not on a simplified fixed-owner statement.
